# Projet Yu-Gi-Oh Back-end

## Description
API back-end construite avec Node.js et Express pour gérer les données de cartes Yu-Gi-Oh.

## Fonctionnalités
- Serveur Express avec plusieurs routes GET (/accueil, /users, /cards)
- Données utilisateurs et cartes simulées en JSON
- Point de départ pour intégration base de données et logique métier

## Technologies utilisées
- Node.js
- Express
- (Prochainement : MySQL, Sequelize)

## Installation & Lancement
1. Cloner le repo
2. `npm install`
3. `npm start` ou `node index.js`
4. Accéder à http://localhost:3000

## Structure du projet
- `index.js` : point d’entrée serveur
- `routes/` (à créer) : routes express
- `controllers/` (à créer) : logique métier
